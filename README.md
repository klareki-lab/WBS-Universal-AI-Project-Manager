# Klare KI — KI Project Studio

React interface, authoritative Node/Fastify + PostgreSQL backend, controlled MCP tools and n8n orchestration.

For the isolated G3 integration runtime, synthetic acceptance scenarios and limitations, see [G3 setup](docs/integration-g3/README.md), [compatibility report](docs/integration-g3/COMPATIBILITY.md) and [acceptance report](docs/integration-g3/REPORT.md).

The canonical API is [Backend OpenAPI v1.1.0](packages/contracts/openapi.yaml). Human approval and the [P1 revocation policy](docs/backend/remediation/APPROVAL_POLICY.md) remain enforced by the backend. This branch is not a production deployment.
